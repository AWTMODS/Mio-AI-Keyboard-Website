## Features Showcased

- Sub-millisecond character insertion (P95 < 0.06ms)
- 100% on-device privacy — zero keystroke telemetry
- Mechanical keyboard soundscapes
- Spacebar trackpad cursor control
- On-device AI text rewriting
- Botanical green-and-cream visual themes

## Development

This is a pure static HTML/CSS/JS site. No build step is needed.

To preview locally, open `index.html` in a browser.

## Hosting

Hosted via [GitHub Pages](https://pages.github.com/) from the `main` branch root.

Enable GitHub Pages in: **Settings → Pages → Source: main branch → / (root)**.
